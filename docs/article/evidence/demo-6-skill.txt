The test counts Slides as a failure, but Slides works. Its `read_presentation` call succeeded with no errors. When the test session started, Slides hadn't finished connecting yet, and the script grades a server by that starting state before it looks at the call results. So a slow-starting server shows as failed even when its calls succeed. The fix would be a small change to the script; I left it alone since you asked for no changes.

If you want Gmail and Drive everywhere, re-register them with `MCP_SCOPE=user`.
